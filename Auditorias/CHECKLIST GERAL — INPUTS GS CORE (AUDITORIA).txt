🔹 A. Estrutura (gate 1)

Herda de GsInputBase

👉 Se falhar aqui, reprova direto.

🔹 B. Controle Interno

Controle interno guardado em campo (_inner)

BorderStyle = None (feito pela base)

Nenhum Controls.Add duplicado

🔹 C. Propagação de Eventos (CRÍTICO)

TextChanged → OnTextChanged

KeyDown → OnKeyDown

KeyPress → OnKeyPress

KeyUp → OnKeyUp

🚨 Esse foi o bug da busca/debounce
Se faltar 1 → UX quebra.

🔹 D. Propriedade Text

override string Text

Getter delega ao _inner

Setter delega ao _inner

Não existe campo duplicado de valor

🔹 E. Validação (CRÍTICO)

❌ NÃO existe Validate()

✔️ Existe public override ValidateInput()

✔️ Chama base.ValidateInput()

✔️ Só valida extra se !HasError

❌ Não lança exceção

❌ Não usa MessageBox

🔹 F. Required

Usa Required

Usa RequiredMessage

Required só valida presença

Required NÃO valida formato

🔹 G. Tema

❌ Nenhum Color.Red, Color.Black, etc.

✔️ Usa tokens do GsTheme

✔️ Reage a troca de tema

❌ Não define cor “na raça”

🔹 H. UX / Acessibilidade

Tab funciona

Enter previsível

Não rouba foco

Erro é local (GsErrorLabel)

Não tem MessageBox

🔹 I. Performance

Não usa reflection

Não cria Bitmap em loop

Não aloca objeto em TextChanged
